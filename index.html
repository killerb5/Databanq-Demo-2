SDK Integration
2 Lines of Code

Drop the DataBanq SDK into your Python or JavaScript codebase. Wrap your existing AI calls and every inference event is automatically logged, policy-checked, and sent to your governance dashboard.

// npm install @databanq/sdk
import DataBanq from '@databanq/sdk'
const dbq = DataBanq.init({ apiKey: 'dbq_live_••••••••' })

// Wrap your existing call — nothing else changes
const res = await dbq.track(openai.chat.completions.create({
  model: 'gpt-4', messages: [...]
}))
